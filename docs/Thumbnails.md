# 네이티브 썸네일

`thumbnail(ImageView, edge, circular, Limits)`은 중앙 정사각형 영역을 크기 `edge`로 변환한다. 원형 모드에서는 가장자리 알파를 보정한다. RGB/RGBA, 행 간격, 투명도를 지원하며 색상 보간은 미리 곱한 알파로 수행하여 투명 픽셀의 RGB가 테두리를 오염시키지 않는다.

ICC 프로필과 해상도 메타데이터는 보존한다. 입력 방향은 1이어야 하며 `decode()`가 방향을 정규화한다. 프로필을 유지한 썸네일과 문서용 sRGB 변환은 별도 연산이다. 파일과 사용자 설정의 저장은 소비자와 iiFileProvider의 책임이다.

`iiImageCodec.Thumbnail`은 중앙 자르기, 원형 마스크, 투명 경계, 메타데이터, 방향 및 저장 한도를 검증한다.
