# 명시적인 ICC 색공간 변환

디코더는 원본 RGB 값과 ICC 프로파일을 보존한다. 문서가 sRGB 작업 공간을 요구하면
`to_srgb(Image)`를 명시적으로 호출한다. macOS는 CoreGraphics, Windows는 WIC,
Linux는 Little CMS 2를 사용한다. 브라우저나 Qt를 사용하지 않으며 파일을 열지 않는다.

입력은 straight-alpha RGBA8이며 변환 결과도 같은 채널 순서와 알파 계약을 사용한다.
좌표·크기·해상도·방향 메타데이터는 변경하지 않는다. RGB가 아닌 ICC 및 잘못된
프로파일은 오류이다. 프로파일이 없는 입력은 sRGB로 간주하여 픽셀을 그대로 반환한다.
프로파일 예산은 1 MiB이며 픽셀 예산도 기존 이미지 코덱 한도를 따른다.

Mac 테스트는 시스템 Display P3 프로파일을 사용하여 색원색 변환, 행 순서와 알파
보존을 검사한다. Windows·Linux의 변환 소스는 해당 OS API를 사용하며 실행 검증은
각 플랫폼 호스트가 있는 환경에서 추가로 수행해야 한다.
